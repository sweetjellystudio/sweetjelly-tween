# Tween UI Dev Sample

This sample shows UI-oriented tween flows for `com.sweetjelly.tween`.

- `TweenUISampleConsumerBehaviour` resolves `ITweenService` from Bootstrapper.
- The sample creates a runtime UI panel with `CanvasGroup`, `Image`, and `TextMeshProUGUI`.
- Buttons demonstrate CanvasGroup fade, Graphic color, Image fill amount, TMP font size, easing, and handle controls.

## Setup

Open `Sample Scene` and enter Play Mode.

Use the on-screen buttons to tween the generated UI elements.
