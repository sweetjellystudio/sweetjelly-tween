# Tween Default Dev Sample

This sample shows the service-driven flow for `com.sweetjelly.tween`.

- `TweenSampleConsumerBehaviour` resolves `ITweenService` from Bootstrapper.
- The sample creates a cube target at runtime.
- Buttons demonstrate transform tweens, grouped tweens, delayed callbacks, easing, and handle controls.

## Setup

Open `Sample Scene` and enter Play Mode.

Use the on-screen buttons to start tweens and control the active handle with pause, resume, complete, and kill.
